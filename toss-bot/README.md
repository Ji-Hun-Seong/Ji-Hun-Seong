- 주 1회(미국 월요일 장중) 조정, 차이 5%p 이상일 때만
- 백테스트: 10년 연 24.0% vs 나스닥100 17.9%, 1990~ 19.9%(MDD -46%) vs 14.1%(MDD -83%)

## 대시보드 (폰 앱처럼)
`dashboard.py` — 서버에서 상시 실행, 폰에서는 **Tailscale**(내 기기끼리만 연결되는 비공개 네트워크)로 접속. 인터넷에 공개되지 않음.
- 홈: 한국·미국 전략 평가, 오늘 할 일(매도 예정·시가 예약·이번 주 TQQQ 목표), 최근 공시, **긴급 정지 버튼**
- 한국: 수익 곡선, 보유 종목(토스 실시간가), 예약, 청산 내역·승률 / 미국: 수익 곡선, QQQ·200일선 차트, 목표 레버리지
- 계좌: 실제 토스 계좌 잔고·보유 종목 / 공시: 감지 기록
- 설치: `bash setup/dashboard.sh` → 폰에 Tailscale 앱 설치·같은 계정 로그인 → `http://toss-bot:8080` → 사파리 공유 → **홈 화면에 추가**
- 실전 전환은 안전을 위해 대시보드에서 못 하고 서버 명령으로만
- **해외 종목**: 미국·일본·중국(상하이·선전)·홍콩·대만·유럽·인도 등 야후 파이낸스가 있는 모든 시장. 한글 이름(토요타·텐센트·마오타이·ASML…),
  숫자 코드(4자리 = 일본, 0으로 시작하는 4자리 = 홍콩, 한국에 없는 6자리 = 중국 A주), 야후 심볼(7203.T·0700.HK·MC.PA), 영문 이름(toyota)으로 검색. 가격은 현지 통화로 표시
- **가족과 공유(조회 전용)**: Tailscale 관리 페이지 → Machines → toss-bot → Share 로 상대 계정에 초대 → 상대는 `http://<서버 100.x IP>:8080` 접속.
  다른 Tailscale 계정에서 들어오면 자동으로 **👀 조회 전용** — 계좌 탭·장기/단기 금액·긴급 정지가 숨겨지고 서버도 변경 요청을 거절(403).
  `.env`의 `DASH_VIEWERS=메일`(같은 계정이라도 조회 전용) · `DASH_OWNERS=메일`(주인 판별이 안 될 때)
