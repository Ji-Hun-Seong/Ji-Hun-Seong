- **🏦 펀드 › 👤 내 펀드**: 토스 실제 계좌를 공모펀드처럼 기준가로 (`chartpage/my_fund.py`, cron 16:10 `fund_sim.py run`이 부름). 산 돈 = 설정, 판 돈 = 환매로 처리해 입출금과 무관한 수익률. 한국 모의 펀드 2개는 2026-11-06 종료(백업 남김)

| 안전장치 | 내용 |
|---|---|
| 🚫 철칙 1 (대출 금지) | `cashBuyingPower`(미수 없는 순수 현금) 안에서만 매수 · 신용·미수 주문 없음 |

| 1회 한도 | `MANUAL_MAX_ORDER_KRW`(기본 3,000,000) · `MANUAL_MAX_ORDER_USD`(기본 2,000) |
| 긴급 정지 | 켜져 있으면 새 매수 차단(매도·취소는 가능) |
