# 심화 서고

펀드로드와 마스터로드의 기초 과정 뒤에 끝없이 쌓는 글. 매일 예약 작업이 주제 하나씩 추가한다.

- 목차: `fund.md`(펀드회계), `market.md`(주식·트레이딩). 맨 위의 안 끝난 `[ ]`부터 쓴다.
- 글: `toss-bot/static/<앱>/deep/topics/YYYYMMDD-slug.json`
- 검사·목록: `python deep-study/build.py` (실패하면 올리지 않는다)

## 글 형식

```json
{"id":"20261110-slug","area":"목차의 ## 제목","t":"주제","date":"2026-11-10","sum":"한 줄 요약",
 "intro":"왜 중요한가",
 "sections":[{"h":"절 제목","b":[
   {"p":"문단"},{"ul":["항목"]},{"tip":"실무·매매 포인트"},{"calc":["계산 한 줄"]},
   {"table":{"head":["열"],"rows":[["칸"]]}},{"f":{"steps":["단계"]}},
   {"j":[{"pre":"날짜·상황","dr":[["계정","1,000",""]],"cr":[["계정","1,000",""]]},{"note":"설명"}]}]}],
 "qs":[["문제",["정답","오답","오답","오답"],"해설"]],
 "src":[{"t":"문서 제목","u":"https://...","o":"기관"}],
 "limits":"확인하지 못한 부분과 회사마다 다른 부분"}
```

## 품질 기준

- 한 글에 8절, 본문 8천 자, 문제 10개, 출처 3개 이상. 기준을 넘겨도 주제가 넓으면 여러 편으로 나눠 깊게 쓴다.
- 법령 조문·세율·한도·날짜·통계는 이번 실행에서 원문을 열어 확인한 것만 쓰고 출처를 단다. 확인 못 하면 쓰지 않고 `limits`에 적는다.
- 숫자 예시는 끝까지 계산하고 가정임을 밝힌다. 원문 문장을 옮겨 적지 않고 자기 말로 쓴다.
- 용어 소개로 끝내지 않는다. 절차, 계산, 예외, 실패 사례, 점검 방법까지 간다.
