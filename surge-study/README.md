## 폴더

- [`reports/`](reports/) — 매일 자동 리포트 (급등주 표, 급등 전날 특징, 공시·뉴스, 차트)
- [`notes/`](notes/) — 매일 분석 노트 (재료 판단, 차트 패턴, 지속성 예상과 다음 날 채점)
- [`PATTERNS.md`](PATTERNS.md) — 누적 패턴 플레이북 (자주 나오는 급등 유형, 근거 표본 수)
- `data/`
  - `universe/날짜.csv.gz` — **전 종목**의 당일 등락·거래대금 + 전날까지의 특징 (급등 안 한 종목과 비교하는 학습용)
  - `daily/날짜.json` — 급등주 상세 (특징·공시·뉴스·자동 재료 분류)
  - `surges.csv` — 급등주 누적 표 + 이후 1·3·5·10거래일 수익률

## 기록하는 특징 (전부 '급등 전날까지' 데이터 → 미래 정보 없음)

- 볼린저: %b, 밴드폭, 밴드폭 6개월 백분위, 스퀴즈 여부
- 추세: 5·20·60·120일선 이격, 정배열, 5·20·60일 수익률, 고점·저점 대비 위치, 연속 상승일
- 거래: 전일 거래량 배수(20일 평균 대비), 20일 평균 거래대금, 외국인 소진율
- 급등 당일: 등락률, 시가 갭, 장중 최고 상승률, 종가 위치(1 = 고가 마감), 윗꼬리, 상한가 여부, 거래량 배수

## 한 달 뒤 계획

1. `universe/` 전체로 "다음 날 +10% 이상" 여부를 맞히는 모형을 만들고, 단순 기준(거래량 급증, 스퀴즈 등)과 비교
2. 재료 유형별(실적, 수주, 임상, 테마 등) 급등 이후 지속률 비교 → 따라 사도 되는 급등 vs 되돌리는 급등 구분
3. 결과를 대시보드 차트 탭의 '급등 후보'로 연결 검토

> 표본이 한 달(약 20거래일)이면 통계적으로 아직 적습니다. 결론은 표본 수와 함께 적고, 계속 쌓으면서 다시 검증합니다. 투자 권유가 아닙니다.
